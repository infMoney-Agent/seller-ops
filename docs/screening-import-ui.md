# 导入页交互

## 信息层级

- 上传区：只保留文件、统计周期、来源月份、观察日期。来源固定卖家精灵，美国站。
- 当前批次：显示文件名、状态、有效与异常行数，以及对应状态的下一步说明；确认导入作为主操作。
- 次要设置：日期与字段映射放入原生 details，识别错误时展开修改。修改未保存时禁止确认并解释原因。
- 数据预览：保留逐行异常、来源行号和可展开的原始数据；错误报告只在存在异常行时显示。
- 历史导入：放在当前批次之后，选中行有背景提示；查看批次后焦点定位到当前批次标题。

## 销量自动识别

新上传固定使用 unknown 作为缺省归属，前端不提供人工切换。
后端优先读取文件明确的子体或父体销量。ASIN 与父 ASIN 相同且变体数为 1 时，子体与父体使用同一销量；无法确定时保留待确认。
查看旧批次时，保留其原有销量元数据，避免仅为界面调整改写历史数据。

## Modern Web Guidance

- content-first-noise-reduction：遵循 “It starts closed”，将次要配置与原始数据保留在可键盘操作的原生 details 中。
- forms：遵循 “non-color visual cues”，状态使用文字及数字；确认不可用时说明具体原因，切换批次时定位标题。
- 复用现有 React Query、服务层与租户校验；不新增依赖或实验浏览器 API。原生 details 在项目支持的当前稳定版浏览器可用。

## 验证

类型检查、ImportPanel 定向 lint、生产构建及隔离数据下的上传→映射重解析→确认导入流程。
浏览器验收同时检查当前批次位于历史之前、切换后的焦点及手动销量归属入口已移除。
