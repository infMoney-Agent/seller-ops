# 商品主表与月度副表改造验证

日期：2026-11-18。所有数据验证均使用独立测试数据库与虚构工作区，未修改线上业务库、人工数据或私有环境配置。

## 当前结构

- 新增`ps_product_monthly`，价格、销量、销售额、评分数、评分和BSR以明确类型保存。
- 商品主表不再包含price_usd、monthly_sales、review_count、rating列，仅保存档案、当前卖家、人工结论与数据引用。
- 支持商品、月份、来源、自然月/滚动30天/自定义周期联合检索；唯一键包含来源和实际起止日期。
- 迁移为`screening_0003`。当前完整DDL见`product-screening-schema.sql`，设计详见`product-screening-database.md`。

## 功能与迁移

- 全部后端回归：**60 passed，4 deselected**。排除项沿用项目原有真实模型测试配置。
- Python静态检查通过；Web类型检查、局部lint和生产构建通过。生产构建保留原有字体fallback及metadataBase提示。
- 验证同一商品多个自然月分别保存、补录旧月不覆盖最新月、同月较新观察递增版本、多来源/滚动窗口互不覆盖、跨工作区隔离。
- 验证价格、销售额、评分以定点字符串返回；缺失值保持NULL，不合并销量、不虚构销售额。
- 验证历史月度利润保存ID/版本/输入快照，历史月度变动后标记过期；批量测算采用所选月份及来源。
- Excel包含“产品初筛”“来源记录”“月度数据”三个工作表。
- 在全新隔离库建立旧版0002结构，写入三个月份、人工结论/备注、操作历史和旧利润方案，再升级0003：所有历史月份回填，原始行、人工状态/备注/版本、事件和利润输出均保留，最新月度引用正确，主表经营列移除。
- 已有入库行的批次禁止修改来源或统计口径；可重试原任务或建立新批次，防止重写历史来源含义。

## 性能复测

独立PostgreSQL14，10万商品、50万来源行、10万分期记录。每场景预热一次并采样7次，P95采用最近秩法，通过ASGI接口实际执行SQL与序列化，不含公网延迟。

| 场景 | P95秒 | 中位数秒 |
| --- | ---: | ---: |
| 全部商品分页 | 0.294 | 0.197 |
| 待复核分页 | 0.519 | 0.395 |
| 机器通过筛选 | 0.510 | 0.377 |
| 指定月份分页 | 0.983 | 0.595 |
| 标题关键词 | 0.775 | 0.372 |
| 汇总统计 | 0.385 | 0.280 |

优化包括：分页/计数仅保留筛选必需联查；按期索引选出每商品有效记录；金额、利润和参考样本仅在当前页丰富；所选月份详情联查限定当前页商品。以上为当前共享测试环境的有限样本，不替代上线后监控。
