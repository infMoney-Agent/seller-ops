# 分组复核与商品页批量复核

商品库的批量复核直接打开已选商品操作窗口，填写结论、原因和备注，先预览后保存，不跳转分组页。原有并发与撤销契约不变。

分组复核左侧为已导入的真实类目树，保留全部级别，不硬凑四级、不在线抓取Amazon目录。选择父节点包含全部后代，商品数与待复核数按当前筛选统计。完整类目路径缺失时采用已有大类和叶类目；都缺失时进入未分类。目录浏览不修改商品归类、父子体关系或人工结论。

右侧继续使用产品方向分组及样本对比；切换类目会清空上一范围的勾选和预览。通过独立只读 review-categories 与 review-workspace category_path 查询实现，不新增表或迁移。

目录使用嵌套列表、独立展开按钮与选中按钮，支持Tab/Enter，不使用缺少方向键模型的伪ARIA tree。窄屏上下排列，保留全部层级和功能。
