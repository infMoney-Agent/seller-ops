# 导入页交互

## 信息层级

- 上传区：只保留文件、统计周期、来源月份、观察日期。来源固定卖家精灵，美国站。
- 当前批次：显示文件名、状态、有效与异常行数，以及对应状态的下一步说明；确认导入作为主操作。
- 次要设置：日期与字段映射放入原生 details，识别错误时展开修改。修改未保存时禁止确认并解释原因。
- 数据预览：保留逐行异常、来源行号和可展开的原始数据；错误报告只在存在异常行时显示。
- 历史导入：放在当前批次之后，选中行有背景提示；查看批次后焦点定位到当前批次标题。

## 销量自动识别

新上传固定使用 unknown 作为缺省归属，前端不提供人工切换。
后端优先读取文件明确的子体或父体销量。ASIN 与父 ASIN 相同且变体数为 1 时，子体与父体使用同一销量；无法确定时保留待确认。
查看旧批次时，保留其原有销量元数据，避免仅为界面调整改写历史数据。

## Modern Web Guidance

- content-first-noise-reduction：遵循 “It starts closed”，将次要配置与原始数据保留在可键盘操作的原生 details 中。
- forms：遵循 “non-color visual cues”，状态使用文字及数字；确认不可用时说明具体原因，切换批次时定位标题。
- 复用现有 React Query、服务层与租户校验；不新增依赖或实验浏览器 API。原生 details 在项目支持的当前稳定版浏览器可用。

## 验证

类型检查、ImportPanel 定向 lint、生产构建及隔离数据下的上传→映射重解析→确认导入流程。
浏览器验收同时检查当前批次位于历史之前、切换后的焦点及手动销量归属入口已移除。

## 商品库统计与排序

统计统一为：商品数（同父体折叠）、子体商品数（去重 ASIN）、待复核（任一子体待复核的父体组数）。数值随筛选动态计算，不写死865/1480。

价格、月销量、利润通过表头按钮切换升降序，服务端按数值在全量筛选结果上排序后分页；缺失值始终最后，同值追加ID稳定排序。利润只读取自行测算记录。采用 sortable-table 的原生按钮和 aria-sort；复用 React 的稳定行键及已有查询状态，不手动修改 React 管理的DOM。加载时旧数据行 inert，保留表头焦点。

## 商品库导入弹卡

独立导入页签移除，商品库页头与空列表提供“导入商品”入口。弹卡采用 native dialog 的 showModal，具名标题及说明、可见关闭按钮和 Esc 关闭；原生焦点约束与焦点返回，不叠加手写焦点陷阱。使用 dialog 指南的 overscroll/backdrop 样式，不隐藏根页面滚动条。弹卡宽度最大48rem、高度85dvh，内容内部滚动。首次打开才挂载导入模块，关闭后保留草稿，切换工作区重置；后台任务独立运行，错误和任务状态在弹卡内显示。历史默认折叠，确认入库校验沿用现有实现。

## 固定格式导入

卖家精灵字段识别由Go后端统一维护。前端移除字段映射、未匹配字段列表、映射保存及重新解析操作；只保留文件、统计周期、来源月份/观察日期、结果预览、错误报告与确认。来源日期缺失的旧批次需重新上传补全，不暴露解析配置。既有来源及映射快照保留，历史接口不因此改写数据。

## 隐藏导入技术任务

导入不展示后台任务卡片、编号、百分比或技术明细；仍监听任务完成以刷新商品和导入记录，保留业务处理状态及失败原因。导入操作使用同步请求锁，后端既有文件哈希/来源期/观察日期唯一约束和批次行事务锁保证重复上传、重复确认复用已有批次与任务；历史记录仍可查。导出、批量测算与规则任务的界面不变。

## 子体优先

子体销量独立保存，卖家精灵“子体销量”数字按购买量下限展示+，原文保留。缺失不取父体值替代；单变体同ASIN推定单独标注。最低子体销量列表筛选只保留已知参考值达到门槛的数据；规则 child_sales_min 下，缺失或下限不足以证明达标时为信息不足。规则试运行与后台任务均读取当前子体经营数据。历史利润输入不随此变化自动调整。

迁移008在经营副表补充 sales_quantity_kind 与 child_sales_raw，不改变人工结论、历史来源或利润输入。来源为reported、lower_bound、single_variant_estimate、missing。child_sales_min 支持列表查询和规则配置；默认不预设业务门槛。父体估算只用于详情参考，不参与子体筛选；不同子体参考值不能直接当作精确父体总量。
