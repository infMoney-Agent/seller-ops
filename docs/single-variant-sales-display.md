# 单变体销量显示

子体销量存在时优先显示；缺失时，仅来源观察记录的变体数为 1，且同一站点、同一父体、同一统计周期没有其他子体或变体数冲突时，使用原始月销量（其次父体月销量）。不要求父子 ASIN 相同。

此规则为查询时回退，不修改原始文件、来源记录、经营数据或机器初筛结论。接口单独返回 display_child_sales，原 monthly_sales / sales_scope 保留。列表、展开子体、历史明细、趋势图共用；销量排序、列表销量门槛按显示值执行。真实子体的加号逻辑保留；推定值不加号也不添加说明标签。旧数据无需重新导入。迁移 010 仅增加同父体/同周期索引，避免每行回退校验扫描全部经营记录；不修改业务数据。

Modern Web Guidance：检索 responsive-table，当前改动只统一数值来源，未改动表格结构和交互，因此不新增布局或浏览器 API。
