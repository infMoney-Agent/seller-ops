## 大库查询

独立PostgreSQL 14测试实例，10万商品、50万来源记录、10万机器结果。脚本为 `apps/backend/scripts/benchmark-screening.py`。每场景预热1次、记录7次，P95采用最近秩法；通过ASGI接口实际执行SQL并序列化响应，不包含公网网络耗时。

| 场景 | P95秒 | 中位数秒 |
| --- | ---: | ---: |
| 全部商品分页 | 0.685 | 0.571 |
| 待复核分页 | 0.891 | 0.782 |
| 机器通过筛选 | 0.816 | 0.779 |
| 标题关键词查询 | 0.879 | 0.803 |
| 数量汇总 | 0.694 | 0.647 |

首轮发现对全量结果排序大JSON字段造成部分场景超过1秒，已改为先对轻量字段分页，再仅加载当前页详情，上表为修复后的结果。此结果是当前共享服务器的有限样本观察，不替代生产负载监控。
