# 产品初筛流程验证与修复（2026-11-19）

本轮沿用 `codex/product-screening`，原 `dev` 工作目录的手工修改保持原样；其中账号绑定租户、移除工作区选择等 21 个文件的修改经三方比较无冲突地合并到功能分支。

## 修复

- 数据库增量迁移 `006_self_parent.sql`：独立商品允许父 ASIN 等于自身，与已修改的 Go 校验一致；保留 ASIN 格式约束，用户管理数据库不变。
- 已知说明页在不含 ASIN 字段时跳过，导入详情展示跳过原因；其他商品页的无效行仍保留错误报告。
- 导入每 500 行提交后更新实际进度。任务失败和批次失败状态同步；租约耗尽也同步；重试恢复批次状态并保留已提交来源行。
- 完成任务清除上次失败信息。数据库约束错误使用可理解的提示和错误代码，不返回原始商品行或 SQL 详情。
- 点击重试同时刷新任务查询缓存，恢复轮询；部分成功任务不再显示不受支持的重试操作。
- 刷新页面后，点击导入记录“查看”可获取 `latest_job_id` 并继续查看后台任务。
- 已有入库数据的批次禁止重新解析映射，避免破坏历史来源关联。
- 来源期从文件名的唯一月份识别，例如 `Product-Beauty&PersonalCare-US-2026.08-430575.xlsx` → `2026-08`；观察日期默认北京时间当天，允许手动覆盖。未知来源期不以当天月份代替。
- 初筛代理根据服务端已验证会话决定租户，不要求浏览器提供工作区选择；旧页面若携带不匹配租户头，仍返回冲突。
