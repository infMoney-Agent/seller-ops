# 按类型分组的批量复核

批量复核不再要求先去商品库选商品。默认浏览商品库当前筛选结果；已有勾选时也可仅查看这些商品。类型组在整个查询结果上分页，每页20组，商品每页50项，参考样本独立分页。

类型组使用站点与既有产品方向，跨卖家展示但不改变归并关系。未初筛且未人工归类的商品各自独立，不根据大类目强行混组。左侧是同类型组已人工复核的样本，支持选择采用和两个样本对比；右侧是原始事实商品卡片，图片、尺寸、重量、卖家、价格及子体销量复用现有字段。样本不足时可直接填写结论。

每次最多明确勾选100项。切换类型组会清空本组勾选、样本与预览，切换同组商品页保留勾选。预览/确认/条件撤销仍复用现有接口，已有人工结论默认不可选；人工归类可选已有结论且不改变结论。样本不会被自动应用。选中样式不改变边框宽度，避免布局跳动。切组只进行一次原生滚动及焦点恢复，不叠加延时滚动补丁。

新增只读 GET /api/ecom/screening/review-workspace，内部同名 /api/v1/screening/review-workspace。查询控制字段 group_page、group_id、member_page、sample_page、selected_ids；其余继承既有筛选白名单。身份与租户由认证代理验证，SQL始终限制当前租户，不增加业务表或迁移。

Modern Web Guidance：card 使用 article、独立链接及有标签的原生勾选；css-layout 使用 Grid 与容器查询，窄容器上下排列且保留 DOM 键盘顺序；forms 保留原生必填校验、显式预览与确认，返回结果用 role=status 宣告。Chrome、Edge、Firefox、Safari 使用 Baseline 容器查询与原生表单，不引入实验 API。
